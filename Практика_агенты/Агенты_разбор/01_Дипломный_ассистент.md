# 01. Дипломный ассистент (ВКР, нормоконтроль)

> Из анкет: «Дипломный агент — помогает красиво оформить дипломную работу» (2 анкеты),
> «Помощник при написании дипломного проекта — работать по методичке, проверять по методичке»,
> «Руководитель ДП (ассистент) — обработка, проверка ДП, выдаёт замечания, отвечает на вопросы»,
> «Проверка ВКР по положению: структура, главы, оформление, список литературы».

## Описание

Агент сопровождает студента и руководителя на этапе дипломного проектирования:
отвечает на вопросы по методичке колледжа, проверяет черновик ВКР на соответствие
положению о нормоконтроле (структура разделов, поля, шрифты, нумерация, оформление
списка литературы по ГОСТ Р 7.0.100), выдаёт список замечаний с указанием страниц.
Содержание работы агент **не пишет** — только проверяет форму и консультирует.

## Способ реализации

1. Собрать базу знаний: методичка по ВКР, положение о нормоконтроле, образец оформления (RAG).
2. Скилл «нормоконтроль»: парсинг .docx через python-docx → проверка стилей, полей, нумерации,
   структуры глав по чек-листу → отчёт с замечаниями в markdown.
3. Скилл «список литературы»: проверка записей на соответствие ГОСТ, подсветка ошибок.
4. Чат-режим «вопрос по методичке» поверх RAG.
5. Уровень кружка: начать с чат-режима (2 занятия), затем добавить парсер docx (4–6 занятий).

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-V3 | Дёшево, длинный контекст для целой главы, доступен из РФ по OpenAI-совместимому API |
| Локальная | Qwen3-14B (Ollama) | Хороший русский, справляется с проверкой по чек-листу; для слабого железа — Qwen3-8B |

## Скиллы

- `normokontrol` — чек-лист проверки оформления + правила вызова парсера docx
- `gost-bibliography` — правила ГОСТ Р 7.0.100 с примерами записей
- `metodichka-qa` — инструкция отвечать строго по загруженной методичке, с цитатой пункта

## MCP

- `filesystem` — чтение работ студентов из папки
- MCP для конвертации документов (pandoc / docx-сервер) — извлечение текста и стилей из .docx

## Почему агент нужен

Нормоконтроль — самая механическая часть руководства дипломами: преподаватель тратит часы на
проверку отступов и списков литературы у 15–25 работ. Правила формальны и записаны в положении —
идеальная задача для автоматизации. Студент получает замечания мгновенно и итеративно правит
работу до сдачи, разгружая руководителя для содержательной работы.

## Почему агент может быть не нужен

Главный риск — студенты начнут делегировать агенту не оформление, а написание текста ВКР,
что подрывает смысл квалификационной работы. Финальный нормоконтроль всё равно подписывает
человек, поэтому юридически агент ничего не заменяет. Часть проверок (поля, шрифты) быстрее
делается обычным шаблоном Word без всякого ИИ.

## Оболочка

**opencode** — лучший выбор: работа целиком файловая (читать docx, писать отчёты), нужны MCP и
запуск python-скриптов. Hermes не подходит — нет файловых инструментов. Для студенческого
чат-режима «вопросы по методичке» можно поднять отдельно Open WebUI с той же базой знаний.
