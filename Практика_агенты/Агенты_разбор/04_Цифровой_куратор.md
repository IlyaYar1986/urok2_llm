# 04. Цифровой куратор группы

> Из анкет: «Классный руководитель — ведение документации по группе» (3 анкеты),
> «Куратор группы — отвечает на вопросы студентов», комментарии: «личные карточки, ведение
> базы данных студентов, журнал посещаемости, координация мероприятий, консультант по
> орг. вопросам».

## Описание

Ассистент классного руководителя: ведёт базу группы (личные карточки, контакты, статусы),
отвечает на типовые организационные вопросы студентов («когда пересдача», «какие документы
на справку»), готовит выгрузки и списки по запросу на естественном языке («все, у кого нет
флюорографии», «список на стипендию»).

## Способ реализации

1. База группы в SQLite (или Google-таблице) — заполняется один раз из существующих списков.
2. Агент получает доступ к базе через MCP и переводит вопросы куратора в SQL-запросы.
3. Отдельный канал для студентов: FAQ-бот в Telegram, отвечающий по базе орг. документов
   колледжа (без доступа к персональным данным группы!).
4. Два контура — куратор (полный доступ, локальная модель) и студенты (только FAQ) —
   важная архитектурная идея для занятия о безопасности.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | GigaChat | Только для студенческого FAQ-контура без персональных данных |
| Локальная | Qwen3-8B (Ollama) — **основной вариант** | Личные карточки — персональные данные (152-ФЗ), наружу не отправляем |

## Скиллы

- `group-db` — схема базы группы и правила SQL-запросов
- `org-faq` — база типовых орг. вопросов и регламентов колледжа
- `privacy-guard` — правило: персональные данные не попадают в ответы студенческого контура

## MCP

- `sqlite` — база группы
- `telegram` (или n8n-узел) — студенческий FAQ-бот
- Google Sheets MCP — если база ведётся в таблицах колледжа

## Почему агент нужен

Куратор в СПО — это десятки рутинных списков и сотни одинаковых вопросов от студентов.
Перевод «вопрос на русском → SQL → список» экономит реальное время каждую неделю, а FAQ-бот
снимает поток сообщений в личку по вечерам. Кейс отлично демонстрирует кружку работу LLM
с базами данных.

## Почему агент может быть не нужен

База группы — это персональные данные несовершеннолетних: любая утечка через промпт или
логи — серьёзный инцидент. Грамотно настроенная Google-таблица с фильтрами закрывает
большинство «выгрузок» без ИИ. FAQ устаревает, и бот начнёт уверенно врать про даты
пересдач, если базу не поддерживать.

## Оболочка

**opencode** для контура куратора (MCP к SQLite, локальная модель через Ollama).
Для студенческого FAQ — **Telegram-бот через n8n** (визуально, школьники соберут сами).
Hermes не подходит: нет доступа к базам и инструментам.
