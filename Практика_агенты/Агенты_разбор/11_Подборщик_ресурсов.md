# 11. Подборщик учебных ресурсов

> Из анкеты: «Агент-подборщик ресурсов — находит и систематизирует научные статьи и видео
> по теме».

## Описание

Агент по теме занятия ищет и систематизирует учебные материалы: статьи (КиберЛенинка,
eLibrary), видеоуроки, открытые курсы, ГОСТы и методички. Выдаёт аннотированный список:
ссылка, 2–3 предложения о содержании, для какого уровня подходит, как использовать на паре.
Может вести «живую» подборку по дисциплине, пополняемую к каждой теме КТП.

## Способ реализации

1. Обязателен инструмент веб-поиска — без него агент будет выдумывать ссылки. Это ключевой
   урок кружку: разница между «LLM из памяти» и «LLM с поиском».
2. Скилл `source-check`: каждую ссылку открыть, убедиться, что страница существует и
   соответствует аннотации; недоступные — отбрасывать.
3. Скилл `annotation`: формат карточки ресурса (что, для кого, как применить).
4. Выход — markdown-подборка по темам КТП, складывается в папку дисциплины.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-V3 | Суммаризация найденных страниц — простая задача, важна цена за объём |
| Локальная | Qwen3-8B | С поиском через MCP даже малая модель даёт честные подборки |

## Скиллы

- `source-check` — протокол верификации каждой ссылки
- `annotation` — шаблон карточки ресурса
- `ktp-collection` — раскладка подборок по темам календарного плана

## MCP

- Веб-поиск + скрейпинг (firecrawl / brave-search) — **обязательно**
- `filesystem` — сохранение подборок

## Почему агент нужен

Поиск хороших материалов — регулярная и плохо масштабируемая работа: на каждую тему уходит
вечер. Агент с поиском делает черновую фильтрацию за минуты, а формат аннотаций превращает
россыпь ссылок в методический ресурс кафедры. Хороший кейс для обучения работе с
инструментами и проверке источников.

## Почему агент может быть не нужен

Без живой проверки преподавателем подборка быстро деградирует: видео удаляются, статьи
за пейволлом, качество материалов агент оценивает поверхностно. Опытный преподаватель
уже знает основные источники по своей дисциплине — польза в основном для новых курсов.
Риск галлюцинированных ссылок полностью не снимается даже с поиском.

## Оболочка

**opencode** с MCP поиска — основной вариант (поиск + файлы + проверка ссылок).
Альтернатива — **n8n**: пайплайн «тема → поиск → фильтр → markdown» по расписанию,
нагляден для школьников. Hermes не подходит: без инструментов поиска агент бесполезен.
