# 08. Конструктор уроков

> Из анкет: «Агент-конструктор уроков по курсу — на вход КТП, выдаёт архив материалов поурочно
> для преподавателя и студентов», «Помощник — план на 90 минут на каждую пару», «Разработчик
> поурочных планов», «Идеи — как интересно провести пары по информатике, математике, физике»,
> «Агент, разрабатывающий образовательные презентации», «Агент-планировщик курса».

## Описание

Агент превращает строку КТП в готовый пакет к паре: план на 90 минут с таймингом, конспект
лекции, презентацию, раздаточные материалы и мини-проверку в конце. Отдельный режим
«идеи» — предлагает 3–5 нестандартных форматов проведения занятия (кейс, игра, дебаты)
под тему и группу.

## Способ реализации

1. Вход: КТП (из агента 07 или вручную) + рабочая программа + предпочтения преподавателя.
2. Скилл `lesson-plan`: структура пары (оргмомент → актуализация → новый материал →
   практика → рефлексия) с таймингом.
3. Скилл `slides`: генерация презентации через Marp (markdown → PDF/PPTX) — школьникам
   очень нравится мгновенный визуальный результат.
4. Скилл `ideas`: банк активных методик, подбор под тему.
5. Пакетный режим: «собери материалы на следующую неделю по КТП».

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-V3 | Большие объёмы генерации (конспекты, слайды) при минимальной цене |
| Локальная | Qwen3-8B | Планы и слайды по шаблону — посильная задача; конспекты лучше на 14B |

## Скиллы

- `lesson-plan` — шаблон плана пары с таймингом и типами активностей
- `slides` — правила Marp-презентаций (структура, лимит текста на слайд)
- `ideas` — каталог активных методик с условиями применимости
- `handout` — раздаточный материал и мини-тест на 5 минут

## MCP

- `filesystem` — КТП на входе, архив материалов на выходе
- Marp CLI (через bash) — сборка презентаций

## Почему агент нужен

Подготовка к парам — ежедневная нагрузка, в отличие от годовой РП: здесь агент экономит время
каждый день. Молодым преподавателям даёт скелет методически правильной пары, опытным —
свежие форматы из режима «идеи». Для кружка это самый зрелищный агент: из одной строки КТП
рождается презентация и раздатка.

## Почему агент может быть не нужен

Сгенерированные конспекты усредняют преподавание: пары становятся одинаково «гладкими» и
безличными, а фактические ошибки в конспекте лекции по спецдисциплине заметит не каждый.
У опытного преподавателя материалы уже накоплены — агент даст ему меньше, чем кажется.
Презентации по шаблону быстро приедаются студентам.

## Оболочка

**opencode** — пакетная генерация файлов, запуск Marp, MCP. Hermes не подходит (нет файлов).
Облегчённый вариант для непрограммирующих преподавателей — Open WebUI с пресет-промптами,
но без автоматической сборки презентаций.
