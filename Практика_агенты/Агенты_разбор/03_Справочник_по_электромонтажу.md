# 03. Справочник по электромонтажу

> Из анкеты: «Справочник по электромонтажу — даёт пояснения по выбору проводов, напряжений
> и электрооборудования силовых щитов».

## Описание

Предметный RAG-справочник для студентов-электромонтажников: отвечает на вопросы о выборе
сечения провода, типах кабелей, автоматах защиты, компоновке силовых щитов — со ссылкой на
конкретный пункт ПУЭ/ГОСТ или страницу учебника. Каждый ответ сопровождается дисклеймером
«проверь по первоисточнику и согласуй с преподавателем».

## Способ реализации

1. Собрать корпус: ПУЭ (актуальная редакция), профильные ГОСТ, учебник, таблицы сечений.
2. Нарезать на чанки, построить векторный индекс (Open WebUI делает это «из коробки»).
3. Системный промпт: отвечать только по найденным фрагментам, всегда цитировать пункт
   нормативного документа, при отсутствии источника — честно говорить «в базе нет».
4. Для кружка: образцовый первый RAG-проект — 2–3 занятия от загрузки PDF до работающего бота.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | GigaChat | Российский контур, неплохо знает отечественную нормативку, бесплатный лимит для учёбы |
| Локальная | Qwen3-8B (Ollama) + bge-m3 для эмбеддингов | Достаточно для извлечения ответов из найденных чанков |

## Скиллы

- `pue-citation` — правило: ответ без ссылки на пункт документа недействителен
- `safety-disclaimer` — обязательная приписка о проверке преподавателем для всего, что
  касается токов, сечений и защитной аппаратуры

## MCP

- Не обязательны: вся ценность в RAG-базе. Опционально MCP веб-поиска для проверки
  актуальности редакции нормативного документа.

## Почему агент нужен

Студенты постоянно задают одни и те же справочные вопросы, а листать ПУЭ они не любят.
Агент с цитированием пунктов приучает к культуре «ответ = ссылка на норматив», что и есть
профессиональный навык электрика. Доступен 24/7, в отличие от мастера производственного
обучения.

## Почему агент может быть не нужен

Цена ошибки высока: неверное сечение провода — это пожар. LLM может галлюцинировать числа
даже при RAG, а студент-первокурсник не отличит правильный ответ от правдоподобного.
Печатные таблицы сечений и справочник на стенде решают 80% тех же вопросов без риска.
Запускать можно только с жёстким цитированием и под контролем преподавателя.

## Оболочка

**Open WebUI** — идеален: веб-чат с встроенным RAG, студенты заходят с любого устройства
в локальной сети колледжа. opencode избыточен (файловая работа не нужна). **Hermes подойдёт**
как минимальный вариант локального чата, но без RAG придётся вставлять выдержки вручную —
для этого агента RAG критичен, поэтому Hermes не рекомендуется.
