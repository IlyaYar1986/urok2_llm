# 10. Анализатор студенческих работ

> Из анкет (4 анкеты): «Агент-анализатор студенческих решений — принимает выполненную работу,
> ищет ошибки, составляет рекомендации, объясняет проблему простым языком, предлагает
> исправленный вариант», «Оценщик — сравнение итога с ожидаемым результатом», «работа над
> ошибками», «проверка д/з», «Агент-оценщик проектов — структурированная обратная связь».

## Описание

Агент проверяет выполненные работы студентов (решения задач, код, лабораторные, домашние
задания): находит ошибки, объясняет каждую простым языком («что не так и почему»),
даёт рекомендации и показывает исправленный вариант. Режим для преподавателя — пакетная
проверка с сводной таблицей типичных ошибок группы.

## Способ реализации

1. Вход: задание + эталон/критерии + работа студента (текст, код, фото рукописи через
   vision-модель).
2. Скилл `error-hunt`: сначала найти ВСЕ ошибки списком, потом объяснять — это предотвращает
   «соскальзывание» модели в пересказ.
3. Скилл `feedback`: формат обратной связи «ошибка → почему это ошибка → как исправить →
   попробуй сам похожий пример».
4. Пакетный режим: папка работ → таблица «студент / ошибки / балл по рубрике» + список
   типичных ошибок для разбора на паре.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-R1 | Поиск ошибок в решениях — задача на рассуждение; для фото рукописей добавить Qwen-VL через OpenRouter |
| Локальная | Qwen3-14B; для фото — Qwen2.5-VL-7B | Vision-модель распознаёт рукописные решения прямо на учебном компьютере |

## Скиллы

- `error-hunt` — протокол двухфазной проверки (сбор ошибок → объяснение)
- `feedback` — педагогический формат обратной связи без готового списывания
- `group-report` — сводка типичных ошибок группы для преподавателя

## MCP

- `filesystem` — папки с работами
- Конвертер документов — docx/PDF работ студентов

## Почему агент нужен

Проверка домашних и лабораторных — главный пожиратель времени преподавателя, и именно она
чаще всего делается поверхностно. Студент получает развёрнутую обратную связь по каждой
работе (на что у человека нет времени), причём мгновенно, пока задача ещё в голове.
Сводка типичных ошибок группы — готовый план следующей пары.

## Почему агент может быть не нужен

Модель находит несуществующие ошибки и пропускает реальные — слепое доверие опаснее ручной
проверки. «Предлагает исправленный вариант» легко превращается в сервис готовых решений:
студенты будут сдавать работу агенту до преподавателя и подгонять под зелёный свет.
По точным дисциплинам автопроверка тестами (Moodle, CodeRunner) надёжнее и без ИИ.

## Оболочка

**opencode** для пакетной проверки преподавателем (файлы, vision через Ollama, отчёты).
Для студенческого режима «проверь себя» — **Open WebUI** с загрузкой фото решения.
Hermes не подходит: нужны файлы и vision.
