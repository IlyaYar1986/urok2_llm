# 16. Планировщик воспитательной работы

> Из анкеты: «Планировщик воспитательной работы в группе — планирует мероприятия
> воспитательного характера на определённый период по группе техникума с датами, целями
> и задачами, подстраиваясь под даты».

## Описание

Агент составляет план воспитательной работы группы на семестр/год: распределяет мероприятия
по календарю (с привязкой к памятным датам, профессиональным праздникам, графику колледжа),
для каждого формулирует цель, задачи, форму проведения и ответственных — в формате
официального плана воспитательной работы, принятого в колледже.

## Способ реализации

1. База: шаблон плана колледжа, календарь памятных дат РФ и Татарстана, программа
   воспитания СПО (федеральная), график учебного процесса (сессии, каникулы).
2. Скилл `vospit-plan`: правила распределения (не ставить мероприятия в сессию, чередовать
   направления — патриотическое, профилактика, профориентация и т.д.).
3. Генерация: семестр → таблица «дата / мероприятие / направление / цель / задачи / форма».
4. Бонус-режим: сценарий конкретного классного часа по выбранной теме.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | GigaChat | Хорошо знает российский календарь дат и терминологию программ воспитания |
| Локальная | Qwen3-8B | Шаблонная генерация по календарю — лёгкая задача |

## Скиллы

- `vospit-plan` — шаблон плана + правила распределения по календарю
- `klassnyi-chas` — структура сценария классного часа
- `calendar-ref` — справочник памятных дат (включая республиканские)

## MCP

- `filesystem` — шаблоны и готовые планы
- Календарь (Google Calendar MCP) — опционально, перенос плана в живой календарь группы

## Почему агент нужен

План воспитательной работы — обязательный документ, который кураторы из года в год
компилируют из старых планов. Агент делает черновик за минуты, не забывает памятные даты
и аккуратно выдерживает требуемые «направления воспитания». Лёгкий, безопасный агент без
персональных данных — хороший первый проект для кружка.

## Почему агент может быть не нужен

Воспитательная работа «из генератора» — это формализм в квадрате: план будет сдан, но
мероприятия останутся на бумаге, и агент лишь ускорит имитацию. Реальные мероприятия
рождаются из интересов конкретной группы, которых модель не знает. Методобъединения
кураторов обычно уже имеют годовые шаблоны — копировать их не дольше, чем промптить.

## Оболочка

Подойдёт любая — задача чисто текстовая. **Open WebUI** с пресет-промптом — самый простой
вариант для кураторов. **Hermes подходит** (редкий случай: чистый текст, локальная модель,
без инструментов). opencode — если нужен сразу docx по шаблону колледжа.
