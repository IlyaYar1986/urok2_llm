# 18. Строительный проектировщик

> Из анкеты (строительная специальность, 3 идеи одного автора): «Создание плана этажа
> с указанием размеров помещений», «Подбор строительных материалов для моделирования и
> строительства будущих зданий и сооружений», «Подбор типа фундамента, высоты, толщины,
> вид кровли, виды лестниц для будущих зданий и сооружений».

## Описание

Учебный агент для дисциплин строительного профиля: по заданию (тип здания, площадь, регион,
грунты) предлагает варианты конструктивных решений — тип фундамента, материалы стен, кровлю,
лестницы — с обоснованием по СП/СНиП и сравнительной таблицей (цена/трудоёмкость/применимость).
Планы этажей генерирует в учебном виде: текстовая экспликация помещений + SVG-схема, как
основа для отрисовки студентом в САПР.

## Способ реализации

1. RAG-база: актуальные СП (СП 22, СП 17, СП 64 и др.), учебники, каталоги материалов.
2. Скилл `konstruktiv`: матрица выбора «условия → варианты решения → плюсы/минусы → пункт СП».
3. Скилл `plan-etazha`: экспликация помещений по нормам площадей → генерация простой SVG-схемы
   (код пишет агент) — далее студент дорабатывает в Renga/AutoCAD.
4. Каждый ответ — со ссылкой на пункт нормативного документа и пометкой «учебное решение,
   не для реального строительства».

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-R1 | Подбор конструктива — многокритериальное рассуждение; R1 лучше держит инженерную логику |
| Локальная | Qwen3-14B | С RAG по СП справляется; SVG-генерация — через код, не «из головы» |

## Скиллы

- `konstruktiv` — методика выбора фундамента/кровли/материалов с привязкой к СП
- `plan-etazha` — нормы площадей помещений и генерация SVG-схем кодом
- `safety-disclaimer` — обязательная пометка об учебном характере решений

## MCP

- `filesystem` — база СП, выходные схемы
- Веб-поиск — проверка актуальности редакций СП и цен материалов

## Почему агент нужен

Курсовое проектирование по строительным дисциплинам — это многовариантный выбор, который
студенты делают плохо («взял как в примере»). Агент показывает альтернативы с обоснованием
по нормативке и приучает аргументировать решения пунктами СП. Сравнительные таблицы
материалов — реальный навык сметчика и техника.

## Почему агент может быть не нужен

Строительство — зона прямой ответственности за безопасность: уверенная галлюцинация о
несущей способности или глубине заложения, попавшая в привычку студента, опасна в будущей
профессии. СП регулярно актуализируются — устаревший RAG вреднее его отсутствия. Настоящие
планы этажей делаются в САПР с проверкой норм — SVG-схема от LLM может закрепить
несерьёзное отношение к чертежу.

## Оболочка

**opencode** — RAG, генерация SVG кодом, файлы. Для режима «справочник по СП» студентам —
Open WebUI с той же базой. Hermes не подходит: справочник без RAG по нормативке будет
галлюцинировать.
