# 06. Экзаменатор

> Из анкет: «Экзаменатор — оценивает ответы студентов на экзамене» (2 анкеты),
> «Составление билетов к экзамену».

## Описание

Агент с двумя режимами: (1) генерация экзаменационных билетов из рабочей программы —
равномерное покрытие тем, сопоставимая сложность вариантов; (2) оценка письменных ответов
студентов по критериям с развёрнутым обоснованием — как «второе мнение» для преподавателя
или тренажёр для самопроверки студента перед экзаменом.

## Способ реализации

1. Вход: рабочая программа + перечень вопросов + критерии оценивания из ФОС.
2. Скилл «билеты»: матрица покрытия тем → генерация N вариантов → проверка на дубли
   и перекос сложности.
3. Скилл «оценка»: рубрика (критерий → балл → признаки) → оценка ответа строго по рубрике
   с цитированием фраз студента → итоговый балл с пояснением.
4. Режим тренажёра: студент отвечает на билет в чате, агент оценивает и показывает пробелы.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-R1 | Оценка по рубрике — задача на рассуждение; R1 даёт воспроизводимые обоснования |
| Локальная | Qwen3-14B (thinking) | Минимальный размер, при котором оценки по рубрике стабильны; 8B заметно «плавает» |

## Скиллы

- `bilety-generator` — правила формирования вариантов (покрытие, сложность, без дублей)
- `rubric-grading` — рубрика оценивания + запрет менять баллы без цитаты из ответа
- `trenazher` — режим репетиции с обратной связью без выставления «оценки в журнал»

## MCP

- `filesystem` — рабочие программы, ФОС, ответы студентов
- Не критичны: агент в основном текстовый

## Почему агент нужен

Составление 25–30 равноценных билетов — нудная комбинаторика, которую агент делает за минуты.
Режим тренажёра — самое ценное: студент получает безлимитную репетицию экзамена с обратной
связью, чего преподаватель физически дать не может. Как «второе мнение» при проверке
письменных работ агент снижает субъективность.

## Почему агент может быть не нужен

Оценка на экзамене — юридически значимое действие преподавателя; передавать её ИИ нельзя
ни по нормам, ни по этике, а «второе мнение» легко превращается в первое и единственное.
LLM нестабильна в баллах (одна работа — разные оценки в разных прогонах) и поощряет
наукообразную «воду», если рубрика нечёткая. Билеты же многие составляют раз в несколько
лет — выигрыш разовый.

## Оболочка

Для преподавателя (билеты, пакетная проверка) — **opencode**. Для студенческого тренажёра —
**Open WebUI** или Telegram-бот: чистый чат, ничего ставить не нужно. **Hermes подходит**
для тренажёра с локальной моделью, если в кабинете один компьютер без сети, но Open WebUI
удобнее для группы.
