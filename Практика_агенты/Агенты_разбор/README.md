# Агенты, предложенные преподавателями СПО Республики Татарстан

Разбор 25 рукописных анкет «Идеи агентов для моего предмета» (папка `Практика_агенты/`).
Всего в анкетах ~60 формулировок; после объединения дублей получилось **26 уникальных агентов**.
Каждому агенту посвящён отдельный файл с описанием, способом реализации, моделями (API + локальная),
скиллами, MCP, обоснованием «за» и «против» и рекомендацией оболочки.

Одна анкета (photo 15.51.34) написана неразборчиво и в подсчёт упоминаний не вошла —
угадываются «агент-ассистент», «LLM на занятии» и «поиск ошибок в работах».

## Общие замечания для кружка

**Персональные данные (152-ФЗ).** Агенты 04, 05, 12, 14, 15, 17, 24 работают с персональными данными
студентов. Для них в файлах рекомендованы локальные модели как основной вариант: данные не должны
уходить во внешние API без обезличивания. Это само по себе хорошая тема занятия.

**Типовые модели.** Через API из РФ реально доступны: GigaChat (Сбер), YandexGPT, DeepSeek (дёшево,
OpenAI-совместимый API). Локально на учебном железе (16 ГБ ОЗУ, желательно GPU): Qwen3-8B / Qwen2.5-7B-Instruct
через Ollama или LM Studio — лучший русский язык среди открытых моделей малого размера.

**Про оболочки.** В файлах сравниваются:
- **opencode** — открытый терминальный агент (аналог Claude Code): инструменты для файлов, bash, поддержка MCP,
  любых OpenAI-совместимых API и локальных моделей через Ollama. Лучший выбор для агентов, которые читают/пишут
  файлы и документы.
- **Hermes** (Nous Research) — чат-оболочка вокруг открытых моделей Hermes; хороша как простой локальный чат,
  но без файловых инструментов и MCP. Подходит только для чисто разговорных агентов. *Если под «hermes»
  имелась в виду другая оболочка — уточните, разбор скорректирую.*
- **Open WebUI** — веб-чат с RAG («знания»), удобен для справочников и ботов для студентов.
- **n8n** — визуальный конструктор пайплайнов с LLM-узлами; лучший выбор для автоматизаций по расписанию
  (ведомости, мониторинг, рассылки) — школьникам нагляднее, чем код.
- **Telegram-бот (aiogram + LLM)** — когда пользователь агента — студент со смартфоном.
