# 25. Помощник проектной деятельности

> Из анкеты: «Агент по проектной деятельности — помогает в поиске информации, анализе
> данных, генерации идей для проектов».

## Описание

Агент-наставник студенческих проектов (индивидуальные проекты, конкурсы, чемпионаты
Профессионалитета): помогает выбрать и сузить тему, провести брейншторм, найти источники,
структурировать данные опросов/экспериментов, собрать план проекта и подготовить защиту
(структура презентации, репетиция вопросов комиссии). Принципиально работает как коуч:
вопросы и варианты вместо готовых кусков текста.

## Способ реализации

1. Скилл `topic-funnel`: воронка темы (широкая область → проблема → исследовательский
   вопрос → выполнимость за семестр).
2. Скилл `brainstorm`: техники генерации (SCAMPER, «а что если»), агент предлагает 10 идей,
   студент отбирает и обосновывает.
3. Поиск источников — через MCP веб-поиска с обязательной проверкой ссылок (как агент 11).
4. Скилл `defense-coach`: репетиция защиты — агент в роли строгого члена комиссии.
5. Антиплагиатный принцип: агент не пишет текст проекта, в системном промпте — жёсткий
   запрет на выдачу готовых разделов.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-V3 | Брейншторм и коучинг — разнообразие идей важнее глубины; дёшево для длинных сессий |
| Локальная | Qwen3-8B | Диалоговый коучинг тянет; анализ данных — кодом через инструменты |

## Скиллы

- `topic-funnel` — методика сужения темы
- `brainstorm` — техники генерации идей с ролью фасилитатора
- `defense-coach` — типовые вопросы комиссии и разбор ответов
- `no-ghostwriting` — запрет писать текст проекта за студента

## MCP

- Веб-поиск (firecrawl/brave) — источники
- `filesystem` — материалы проекта, данные опросов

## Почему агент нужен

Индивидуальный проект — обязателен по ФГОС, но руководитель ведёт по 10–15 проектов и
физически даёт каждому 15 минут в неделю. Агент закрывает «межконсультационные» вопросы и
учит главному — задавать вопросы и структурировать мысль. Репетиция защиты — то, чего
студенты не получают почти никогда.

## Почему агент может быть не нужен

Грань между «помог структурировать» и «сделал за студента» тонкая, и студенты будут её
продавливать — без жёсткого no-ghostwriting агент превращается в фабрику проектов, которые
комиссия и так уже научилась распознавать. Смысл проектной деятельности — самостоятельное
преодоление хаоса; слишком удобный помощник этот опыт крадёт.

## Оболочка

**Open WebUI** с поиском — студенты работают сами, преподаватель видит историю. **Hermes
подходит** для коуч-режима без поиска (чистый диалог). opencode — для этапа анализа данных
(опросы, таблицы, графики кодом), студентам ИТ-специальностей это плюс.
