# 12. Карьерный навигатор

> Из анкет (2 анкеты): «Карьерный навигатор (помочь выпускникам: учёба → карьера/работа) —
> анализ данных об успеваемости и базы вакансий», «Карьерный навигатор — подбирает вакансии
> и навыки, актуальные для студентов».

## Описание

Агент помогает выпускнику СПО построить трек «специальность → вакансии региона → недостающие
навыки»: анализирует открытые вакансии по профессии в Татарстане (hh.ru и др.), извлекает
требуемые навыки, сопоставляет с программой обучения и успеваемостью студента, выдаёт
персональный план: какие вакансии реалистичны сейчас, что подтянуть, какой курс/сертификат
добавить.

## Способ реализации

1. Открытое API hh.ru (бесплатное, без ключа для поиска вакансий) — готовый источник данных:
   вакансии по запросу и региону, зарплаты, требования.
2. Скилл `skill-extract`: из текстов 30–50 вакансий извлечь и ранжировать навыки.
3. Скилл `gap-analysis`: сопоставить навыки вакансий с дисциплинами учебного плана →
   таблица «есть в программе / надо добрать самому».
4. Чат-режим для студента: «кем я могу работать после 09.02.07?» — без передачи его
   персональных данных, успеваемость студент вводит сам обобщённо.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-V3 | Извлечение навыков из сотен вакансий — дёшево и параллельно |
| Локальная | Qwen3-8B | Если в анализ добавляется реальная успеваемость студента — только локально |

## Скиллы

- `hh-search` — правила запросов к API hh.ru (регион Татарстан, профроли СПО)
- `skill-extract` — извлечение и нормализация навыков из вакансий
- `gap-analysis` — сопоставление с учебным планом, формат личного плана

## MCP

- HTTP/fetch MCP или самописный MCP-сервер hh.ru — отличный учебный проект «пишем свой MCP»
- `filesystem` — учебные планы, отчёты

## Почему агент нужен

Прямое попадание в миссию СПО — трудоустройство. Данные реальные и открытые (hh.ru),
результат осязаемый для каждого выпускника, а для кружка это лучший проект про
«LLM + внешний API»: студенты сами видят, какие навыки рынок требует от их профессии.
Профориентационная работа в колледжах обычно формальна — агент делает её предметной.

## Почему агент может быть не нужен

Вакансии hh.ru смещены к офисным профессиям — рабочие специальности там представлены хуже
(многие наймы идут мимо площадок), и картина рынка будет искажённой. Советы по карьере
несовершеннолетним — чувствительная зона: модель может уверенно рекомендовать сомнительное.
Центры карьеры колледжей формально уже выполняют эту функцию.

## Оболочка

**opencode** — для разработки (свой MCP к hh.ru, анализ, отчёты). Для студентов финальную
версию удобнее завернуть в **Telegram-бота** или Open WebUI. Hermes не подходит: без HTTP-
инструментов агент не получит вакансии.
