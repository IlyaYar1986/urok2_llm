# 21. Агент-логистик

> Из анкеты (4 идеи одного автора): «Составлять план занятия ИИ в логистике», «создавать
> упражнения, задачи для логиста с применением математики и ИИ», «работа над ошибками»,
> «делать отчёт».

## Описание

Предметный агент для специальности «Операционная деятельность в логистике»: генерирует
практические задачи с реальными данными (маршруты по Татарстану, тарифы, складские
ограничения), решает их эталонно через код (транспортная задача, EOQ, маршрутизация),
проверяет решения студентов с разбором ошибок и собирает отчёт по группе. Заодно —
план занятия «ИИ в логистике» как тема профориентации.

## Способ реализации

1. Скилл `task-gen`: шаблоны классических задач логистики (транспортная, управление
   запасами, выбор перевозчика) с параметризацией под реальные города и тарифы.
2. Эталонное решение — **кодом** (scipy/OR-Tools), не «из головы» модели: студенты сверяют
   и своё решение, и решение LLM с математическим эталоном — мощный учебный момент.
3. Скилл `error-review`: разбор решения студента по шагам с локализацией ошибки.
4. Демо для пар: «как Wildberries строит маршруты» — агент показывает живую оптимизацию.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | DeepSeek-R1 | Разбор решений с арифметикой — нужна reasoning-модель + проверка кодом |
| Локальная | Qwen3-14B | Генерация условий и разбор ошибок; вся математика — в scipy |

## Скиллы

- `task-gen` — каталог типов задач с параметризацией под регион
- `solver` — правила вызова scipy/OR-Tools для эталонов
- `error-review` — пошаговый разбор решения студента

## MCP

- `filesystem` — банки задач, работы студентов, отчёты
- Веб-поиск — актуальные тарифы перевозчиков для правдоподобных условий

## Почему агент нужен

Задачники по логистике стареют мгновенно (цены, маршруты), а агент генерирует свежие
условия с местной географией — задачи про Казань–Челны мотивируют сильнее, чем «пункт А —
пункт Б». Связка «LLM-условие + солвер-эталон» даёт неограниченный банк задач с гарантированно
верными ответами. Профессия логиста реально меняется ИИ — показывать это на парах честно.

## Почему агент может быть не нужен

Один автор, одна дисциплина — масштаб пользы ограничен кафедрой. Без дисциплины «эталон
только кодом» агент будет путаться в арифметике и подрывать доверие. Классических задачников
и Excel-практикумов по логистике достаточно для программы — агент здесь улучшение, а не
необходимость.

## Оболочка

**opencode** — запуск солверов, файлы, банки задач. Для студенческого режима «реши и проверь» —
Open WebUI с code-interpreter-функцией. Hermes не подходит: арифметика без выполнения кода —
источник ошибок.
