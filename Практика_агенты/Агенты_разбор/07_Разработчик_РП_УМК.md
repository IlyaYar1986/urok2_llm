# 07. Разработчик РП и УМК (ФГОС, КТП, ФОС)

> Из анкет: «Личный ассистент по разработке рабочих программ — структура и требования ФГОС,
> подключить базу знаний» (с упоминанием Yandex AI Studio), «Составление раб. программ —
> загружаем ФГОС, примеры + ФОСы», «Разработка УМК по дисциплине (раб. прогр., КТП, ФОСы,
> лекции, планы уроков, ПР, тесты, задания к ДЗ и экзамену)», «РП, по ней КТП, лекции, тесты,
> презентации», «Методист — составление КТП по заданным параметрам». Самый массовый запрос —
> 6 анкет.

## Описание

Агент-методист: из ФГОС СПО по специальности, учебного плана и примеров готовых программ
собирает каркас рабочей программы дисциплины, из неё — календарно-тематический план с датами,
далее — заготовки ФОС. Работает каскадом: каждый следующий документ строится из предыдущего,
преподаватель утверждает промежуточные результаты.

## Способ реализации

1. База знаний: ФГОС по специальности, макет РП колледжа, 2–3 утверждённые программы как образцы.
2. Пайплайн скиллов: `rp-skeleton` (РП по макету) → `ktp-builder` (разбивка часов по датам
   с учётом графика учебного процесса) → `fos-draft` (паспорт ФОС по компетенциям).
3. Контрольные точки: агент останавливается после каждого документа и ждёт правок.
4. Выход — docx по макету колледжа (pandoc + шаблон).

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | GigaChat Max или DeepSeek-V3 | Длинные структурированные документы; GigaChat лучше знает терминологию ФГОС, DeepSeek дешевле |
| Локальная | Qwen3-14B | Каркасы и КТП тянет; для слабого железа 8B с более дробными шагами |

## Скиллы

- `rp-skeleton` — макет РП колледжа + правила переноса компетенций из ФГОС
- `ktp-builder` — алгоритм раскладки часов по неделям с учётом праздников и сессий
- `fos-draft` — структура ФОС: паспорт, типовые задания по каждому ОК/ПК

## MCP

- `filesystem` — ФГОС, макеты, образцы
- Веб-поиск (firecrawl/brave) — проверка актуальной редакции ФГОС на reestrspo / fgos.ru
- pandoc — выгрузка в docx по фирменному шаблону

## Почему агент нужен

Самый частый запрос преподавателей — и понятно почему: РП и УМК — десятки страниц
формализованного текста по жёсткому макету, переписываемые при каждом обновлении ФГОС.
Структура документов настолько регламентирована, что LLM заполняет её отлично. Экономия —
дни работы на каждую дисциплину; качество каркаса стабильнее, чем при копировании старых
программ.

## Почему агент может быть не нужен

РП — официальный документ: сгенерированные часы и темы, не выверенные методистом, поедут
по всей отчётности. Есть риск конвейера «программ, которые никто не читает» — формализм
лишь ускорится. Многие колледжи уже используют конструкторы РП (и шаблоны методобъединений),
где ИИ ничего не добавляет.

## Оболочка

**opencode** — однозначно: многофайловый пайплайн, MCP, docx-выгрузка, длинные документы.
Hermes для этой задачи непригоден. Упомянутый в анкете Yandex AI Studio — рабочая
альтернатива (визуальный конструктор ассистента с базой знаний), но без файлового вывода
в макет колледжа; для кружка opencode даёт больше учебного материала.
