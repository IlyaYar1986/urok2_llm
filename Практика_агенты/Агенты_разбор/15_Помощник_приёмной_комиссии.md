# 15. Помощник приёмной комиссии

> Из анкет (2 анкеты): «Помощник при работе приёмной комиссии — посчитать баллы по аттестату,
> консультация по специальностям», «Анкета — создание личной карты студента (абитуриента):
> заявление, анкета, специальность, ранжирование, телефон, данные о родителях».

## Описание

Два контура: (1) публичный консультант для абитуриентов — отвечает на вопросы о
специальностях, проходных баллах, документах и сроках, считает средний балл аттестата и
оценивает шансы по конкурсным спискам прошлых лет; (2) внутренний помощник секретаря —
формирует личную карту абитуриента из заявления, проверяет комплектность документов,
ранжирует списки.

## Способ реализации

1. Публичный контур: RAG-бот по правилам приёма колледжа + калькулятор среднего балла
   (скрипт, не LLM) + таблица проходных прошлых лет. Telegram или виджет на сайте.
2. Внутренний контур: скилл `lichnaya-karta` — извлечение полей из сканов заявлений
   (vision-модель) → структурированная запись в базу → чек-лист комплектности.
3. Сезонность: агент нужен июнь–август, остальное время спит — хорошо для пилота.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | GigaChat | Публичный FAQ без персональных данных; российский контур для сайта колледжа |
| Локальная | Qwen2.5-VL-7B + Qwen3-8B | Внутренний контур: сканы заявлений с паспортными данными — только локально |

## Скиллы

- `priem-faq` — правила приёма, сроки, перечень документов (обновляется ежегодно!)
- `ball-calc` — порядок расчёта среднего балла аттестата (скриптом)
- `lichnaya-karta` — схема полей карты абитуриента и чек-лист комплектности

## MCP

- `telegram` / веб-виджет — публичный бот
- `sqlite` + `filesystem` — карты абитуриентов, сканы
- Vision-конвертер (локальный) — распознавание заявлений

## Почему агент нужен

В сезон приёмная комиссия отвечает на сотни однотипных звонков — FAQ-бот снимает 70% потока
и работает ночью, когда родители и абитуриенты реально ищут информацию. Подсчёт баллов и
проверка комплектности — формальные операции с очевидной автоматизацией. Для колледжа это
ещё и имиджевая витрина цифровизации.

## Почему агент может быть не нужен

Цена ошибки публичного бота высока: неверный ответ о сроках или документах — реальные
жалобы и потерянные абитуриенты; правила приёма меняются каждый год, и устаревший RAG
опасен. Внутренний контур обрабатывает паспортные данные несовершеннолетних — максимальные
требования 152-ФЗ. Региональные сервисы (ЕПГУ — приём в СПО через Госуслуги) уже закрывают
часть функций.

## Оболочка

Публичный бот — **n8n + Telegram** (визуальная сборка, удобно сопровождать) или Open WebUI
для стойки в холле. Внутренний контур — **opencode** с локальными моделями. Hermes не
подходит ни для одного контура.
