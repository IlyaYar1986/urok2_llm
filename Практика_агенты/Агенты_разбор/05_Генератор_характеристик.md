# 05. Генератор характеристик студентов

> Из анкет: «Помощник куратора — составляет характеристику студента, шаблон (персонализирую
> в конце я)», «Формирование характеристик студентов», «Создание характеристики на студента».
> Идея встречается в 3 анкетах — одна из самых частых.

## Описание

Агент собирает черновик характеристики студента (для военкомата, перевода, практики,
стипендиальной комиссии) из структурированных данных: успеваемость, посещаемость, участие
в мероприятиях, заметки куратора. Выдаёт текст по официальному шаблону колледжа, куратор
персонализирует и подписывает.

## Способ реализации

1. Анкета-источник: мини-форма на студента (5–7 полей: успеваемость, дисциплина, активность,
   сильные стороны, особенности) — заполняется галочками за минуту.
2. Скилл с шаблоном характеристики и банком корректных формулировок («проявляет
   ответственность», «требует контроля» и т.п.).
3. Агент: данные формы → связный текст по шаблону → docx через pandoc.
4. Пакетный режим: характеристики на всю группу из таблицы за один прогон.

## Модели

| Вариант | Модель | Почему |
|---|---|---|
| API | — не рекомендуется | ФИО + оценки + поведение = персональные данные, наружу не отправляем |
| Локальная | Qwen3-8B (Ollama / LM Studio) — **основной вариант** | Шаблонная генерация по структурированным данным — лёгкая задача даже для 8B |

## Скиллы

- `harakteristika-template` — официальный шаблон + банк формулировок по уровням
  (отлично/хорошо/удовлетворительно по каждому критерию)
- `batch-mode` — правила пакетной генерации из CSV-таблицы группы

## MCP

- `filesystem` — чтение таблицы группы, запись docx
- Конвертер md→docx (pandoc)

## Почему агент нужен

Характеристики — чистая шаблонная бюрократия: куратор пишет десятки в год, и 90% текста
повторяется. Запрос фигурирует в трёх анкетах — боль реальная. Структурированный вход
(галочки вместо сочинения) ускоряет работу с 20 минут до 2 на студента и выравнивает
качество формулировок.

## Почему агент может быть не нужен

Характеристика — документ с правовыми последствиями (военкомат, суд, опека): шаблонные
ИИ-тексты «под копирку» на всю группу обесценивают документ и заметны получателю.
Если куратор перестаёт думать над текстом, теряется смысл характеристики как
персонального мнения педагога. Задача решается и обычным шаблоном Word с автозаменой.

## Оболочка

**opencode** с локальной моделью через Ollama: файловый ввод-вывод, пакетный режим, ничего
не уходит в облако. **Hermes условно подходит** для разовой генерации (вставить данные руками,
скопировать текст) — это самый простой старт, но без пакетного режима и docx. n8n — если
хочется формы и автоматической раскладки по папкам.
