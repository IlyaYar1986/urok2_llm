# 02. Ассистент по курсовым работам

> Из анкет: «Ассистент по КР и ВКР — обработка и анализ текста», «Помощник по написанию
> курсовой — по методичке отвечает на вопросы, проверка рабочего варианта и выявление ошибок
> в оформлении», «Агент, проверяющий курсовые — объект, предмет, цели, задачи, структура,
> теория, практическая часть», «Проверка ПЗ курсовых — загружается шаблон и требования»,
> «Создание рецензии на инд. проект, курсовую работу», «Проверка отчётов по практике».

## Описание

Младший брат дипломного ассистента, но с акцентом на содержательную структуру: агент проверяет,
что во введении корректно сформулированы объект, предмет, цель и задачи, что задачи отражены в
главах и выводах, что практическая часть соответствует теме. Дополнительно — черновик рецензии
для руководителя и проверка отчётов по практике по шаблону.

## Способ реализации

1. RAG-база: методичка по курсовым, шаблон ПЗ, критерии оценки, примеры хороших работ.
2. Скилл «структурный аудит»: промпт-цепочка — извлечь объект/предмет/цели/задачи → сверить
   с содержанием глав → таблица соответствия с пометками «раскрыто / частично / нет».
3. Скилл «рецензия»: генерация черновика рецензии по фиксированной форме колледжа,
   преподаватель только правит и подписывает.
4. Для кружка: отличная демонстрация chain-of-thought — студенты видят, как разбивать
   большую проверку на шаги.

## Скиллы

- `structure-audit` — методика сверки введения с главами и выводами
- `recenziya` — форма рецензии колледжа + тон и типовые формулировки
- `praktika-report` — чек-лист отчёта по практике

## MCP

- `filesystem` — папки групп с работами
- Конвертер документов (docx→md) — тот же, что у агента 01

## Почему агент нужен

Курсовых в разы больше, чем дипломов, а типовые ошибки одни и те же («цель не согласована с
задачами», «вывода по главе нет»). Агент даёт студенту раннюю обратную связь до того, как
работу увидит преподаватель, и поднимает средний уровень сдаваемых работ. Черновики рецензий
экономят преподавателю часы чисто бюрократического письма.

## Почему агент может быть не нужен

Содержательная оценка курсовой — это и есть работа преподавателя; если её делегировать,
оценивание становится формальностью и студенты быстро учатся «писать под ИИ-проверку».
Рецензия, сгенерированная ИИ и не прочитанная человеком, — профанация документа. Для
маленьких групп (5–8 работ в семестр) выигрыш времени не окупает настройку.

## Оболочка

**opencode** для пакетной проверки работ преподавателем (файлы, скрипты, MCP).
Для студентов — **Open WebUI** с базой знаний методички: чат «спроси у методички» без доступа
к чужим работам. Hermes — только если нужен совсем простой локальный чат без RAG.
